# GTA VI Trophy Guide — All 55 PS5 Trophies, Roadmap & Tracker

An offline guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI: 1 Platinum, 2 Gold, 6 Silver, 46 Bronze. Every trophy is shown with its official name, description and grade exactly as PlayStation publishes it, plus a guide written in our own words that cites its source (KeenGamer and GTA BOOM), a three-stage roadmap to the Platinum (~200 hours, difficulty 4/10, 1 playthrough, 0 online trophies), and a clear flag on the one missable trophy — **Positive Mental Attitude** (meditate at all 18 spots, including the Chapter 1 balcony spot before Chapter 1 ends).

The tracker is a dense, dark "game wiki" table: tick trophies off and progress saves in your browser (localStorage), export it to JSON and import it back, filter by grade, category, earned/locked, missable-only or hidden-only, search by name, and turn the spoiler guard on or off (on by default: story and hidden trophies stay masked until earned). Click any row for the full guide and its sources.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Static files only — `app/index.html` opens in desktop Chrome with the network off. No build step, no network requests at run time, no Rockstar logo or official artwork anywhere.

## Hand it in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies `app/` and `screenshots/` to the output folder and writes `dossier.json` with the vendored make.fun helper.
